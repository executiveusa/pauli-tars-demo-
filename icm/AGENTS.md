# BARS / TARS Agent Roles & Hierarchy

## Agent Definitions
1. **BARS Sovereign Operator**: Primary conversational agent persona managing user interactions, squad delegation, and mission summaries.
2. **Squad Minions**:
   - `Researcher`: Web scraping, factual verification, and evidence synthesis.
   - `Coder (OpenCode)`: Bounded code inspection, modification, testing, and patch creation.
   - `Auditor`: Security scanning, secret detection, and lint checking.
3. **PORTER (Deployment Operator)**: Autonomous release manager verifying builds, recording receipts in Supabase, and communicating with ChatGPT governor.
