# BARS / TARS Product Specification

## Mission & Purpose
BARS (Boutique Autonomous Robotic Squad / formerly TARS) is the owner-operated autonomous execution operator and voice-enabled conversational AI system for The Pauli Effect ecosystem.

## Core Personas & Roles
1. **BARS Conversational Operator**: Hip-hop culture-infused, high-agency autonomous agent capable of natural voice interaction, rapid decision-making, and proactive execution.
2. **Headless Squad Members**: Specialized background execution workers dispatched for targeted research, scraping, audits, tool execution, and coding.
3. **Sovereign Worker Node (`bambu-windows-01`)**: Local machine execution environment commanding local CLI tools, browser automation, and file system operations.

## Key Capabilities
- **Real-Time Voice**: Low-latency duplex speech input/output powered by ElevenLabs voice synthesis.
- **Dynamic Model Router**: Intelligent request classification routing across 5 distinct lanes (`DIRECT`, `FLASH`, `WORKER`, `REASONER`, `JUDGE`) with explicit manual model override.
- **Constrained Coding Execution**: Safe, bounded coding tool path dispatched through Terabithia authority.
- **Outbound Sovereign Bridge**: Outbound connection to Terabithia Control Plane without exposing local ports to the internet.
