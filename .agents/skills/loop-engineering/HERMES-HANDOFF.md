# Hermes handoff — Loop Engineering

BARS has one canonical engineering governor: `.agents/skills/loop-engineering/SKILL.md`.

For every product/repo/creative-system request:
1. invoke Loop Engineering;
2. resume the active ICM run instead of starting a second control plane;
3. establish or confirm the bar before substantial work;
4. activate only the specialist expertise required by the current stage;
5. use fresh worker/verifier contexts for builder/critic separation;
6. keep durable truth in run artifacts, not chat memory;
7. execute bounded graph nodes, one writer per artifact;
8. require owner approval only at explicit consequential gates;
9. never claim production verified without exact-revision runtime proof;
10. end every major cycle with a receipt: decision, changes, proof, status, commercial impact, risks, rollback, next, human approval.

Voice and typed commands are equivalent intent surfaces. Voice never bypasses approval, policy, evidence, or release gates.

Useful commands: `LOOP`, `SCAN`, `LOCK`, `GRAPH`, `SPEC`, `SLICE`, `BUILD`, `PROOF`, `GAUNTLET`, `SHIP`, `ROLLBACK`, `NEXT`.
